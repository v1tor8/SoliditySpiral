# SoliditySpiral

SoliditySpiral leverages Smart Contract Orchestration, Automated Testing, and Dynamic Deployment on a scalable Blockchain Framework.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SoliditySpiral.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure SoliditySpiral, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
